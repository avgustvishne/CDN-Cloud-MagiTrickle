# Политика безопасности

Этот репозиторий публикует CIDR-подписки, которые люди напрямую подключают
в свой роутер как правило маршрутизации. Из-за этого здесь два разных
класса проблем, и они требуют разного обращения.

## Подозрительные или вредоносные данные в подписке

Если в одном из сгенерированных `.txt`-файлов оказалась подсеть, которая
явно не принадлежит заявленному провайдеру — **не открывай публичный
issue с деталями сразу**. Опиши проблему через [GitHub Security
Advisories](../../security/advisories/new) в этом репозитории — это
приватный канал, видимый только мейнтейнерам, пока проблема не будет
подтверждена и исправлена. После исправления мы раскроем детали публично.

Приложи:
- какой файл и какая именно CIDR-запись вызывает подозрение;
- почему — например, whois/RIPEstat показывает другого владельца ASN;
- если можешь — ссылку на источник, который должен подтвердить/опровергнуть.

## Уязвимости в самом коде или пайплайне

Например: способ подменить `config/providers.json` или `config/policy.json`
через PR так, чтобы это не было замечено ревью, или обойти
`regression_gate.py`/`rollback_guard.py`. Такие проблемы тоже сообщай через
[Security Advisories](../../security/advisories/new), не через обычный issue.

## Обычные баги и предложения

Всё остальное — сломанный провайдер, неверная документация, идеи по
улучшению — как обычно, через [Issues](../../issues) или см.
[CONTRIBUTING.md](CONTRIBUTING.md).
