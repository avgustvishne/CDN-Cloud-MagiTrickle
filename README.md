## 🔢 ASN-подписки

ASN-подписки строятся из актуальных BGP-анонсов через несколько источников. Список ASN расширен только проверенными ASN соответствующих операторов; повторяющиеся ASN внутри провайдера автоматически удаляются.

Для общего набора **все полученные CIDR дополнительно нормализуются, дедуплицируются и агрегируются**, поэтому одинаковый адрес не дублируется в `asn-all-v4/v6`.

### Provider vs ASN

- **Provider** — широкое покрытие инфраструктуры провайдера.
- **ASN** — более точечный выбор автономной системы.
- **ASN ALL** — объединённый набор всех ASN проекта с удалением дубликатов и агрегацией CIDR.

## 🧪 Диагностика DPI

Для разбора лога MagiTrickle есть отдельный классификатор:

```bash
python scripts/dpi_classifier.py dpi.log -o dpi-report.json
```

Статусы объединяются по узлу:

- `detected` — подтверждённый результат;
- `possible` — возможный результат;
- `unlikely` — слабый сигнал;
- `safe` — `not detected`;
- `dead` — узел недоступен.

`alive: yes` и `alive: unknown` не считаются результатом DPI-теста.
