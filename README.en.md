## ✨ Features

- IPv4 / IPv6 CIDR
- ASN subscriptions
- CDN / Cloud / Video / VPN sets
- **FULL / BALANCED / LITE** profiles
- Provider-specific lists
- Combined **ASN ALL** lists
- Automatic updates
- Duplicate CIDR removal and CIDR aggregation

## ⚡ Quick start

If you are not sure which list to use, start with **BALANCED**.
